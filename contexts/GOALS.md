## Retired

Keep a short record after an outcome reaches a terminal state. Link a dated context narrative when one exists.

## Lifecycle rules

1. Copy [`GOAL_TEMPLATE.md`](GOAL_TEMPLATE.md) into a root file named `GOAL_<SHORT_NAME>.md`.
2. Add one row to the active table.
3. Keep exactly one workboard item marked **IN PROGRESS**.
4. Update evidence after each meaningful check or external state change.
5. Move the registry entry to **Retired** when the requested goal is complete, cancelled, or explicitly blocked/handed off.
6. Do not silently convert optional polish or newly discovered adjacent work into required goal criteria.
